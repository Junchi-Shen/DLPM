# Conditional Deep Levy Process Models

This is the clean research release for the final conditional DLPM study.  It
contains the implementation that underlies the paper, the reproducible
experiment entry points, compact reported summaries, and the full LaTeX
source.  It intentionally excludes raw market data, model checkpoints,
generated path archives, old prototypes, exploratory figures, caches, and
intermediate results.

## What is included

- Conditional DLPM with history-aware conditioning and finance-aware path
  regularization.
- Gaussian DDPM and statistical-baseline evaluation entry points.
- Neural SDE and Chronos zero-shot external baseline entry points; Chronos is
  optional because it requires a separately installed upstream package/model.
- Student-t GARCH risk-neutral benchmark utilities used by the P-Q diagnostic.
- Audited P-Q alignment, drift-neutral, static delta-hedge, Monte Carlo quote
  uncertainty, regime-conditional, and structured-product audit scripts.
- The final paper source in `paper/`, including compact tables, figures, and
  data summaries needed to compile it.

## Repository layout

```text
src/dlpm/       model, data preparation, payoff and configuration modules
scripts/        train, generate, evaluate and audit entry points
configs/        frozen experiment-suite configuration example
data/           documented placeholder for local datasets
artifacts/      documented placeholder for local weights and archives
paper/          LaTeX manuscript, figures and compact result data
tests/          lightweight payoff smoke tests
```

## Quick start

Create an environment with Python 3.10+ and install the project in editable
mode. This resolves the legacy top-level modules from `src/dlpm` consistently
on Windows, macOS, and Linux:

```bash
python -m pip install -r requirements.txt
python -m pip install -e .
```

Alternatively, expose the source tree without installing the project.
On macOS/Linux:

```bash
export PYTHONPATH="$PWD/src/dlpm"
```

On PowerShell:

```powershell
$env:PYTHONPATH = "$PWD\\src\\dlpm"
```

On Windows Command Prompt:

```bat
set PYTHONPATH=%CD%\src\dlpm
```

Point the code at local large artifacts when they are not stored below this
repository:

```powershell
$env:DLPM_DATA_ROOT = "D:\\path\\to\\Dataset_Purged"
$env:DLPM_ARTIFACT_ROOT = "D:\\path\\to\\artifacts"
```

Example commands:

```bash
python scripts/run_clean_split_training.py --variant dlpm_hybrid
python scripts/evaluate_path_models.py --help
python scripts/run_neural_sde_baseline.py --help
python scripts/run_chronos_baseline.py --help
python scripts/generate_rnq_paths.py --help
python scripts/audit_rnq_martingale.py --help
python scripts/audit_effective_tail_behavior.py --help
python scripts/run_economic_attribution.py --help
python scripts/run_structured_product_audit.py --help
python scripts/build_release_artifacts.py
```

The complete path and economic runs require the processed split, checkpoint,
fitted processor, 40-path P archive, and 256-path RN-Q archive. Raw licensed
market data and these large binary artifacts are not stored in Git. Their
schemas and SHA-256 identities are documented in `data/README.md`,
`artifacts/README.md`, and `artifacts/ARCHIVE_MANIFEST.json`.

`scripts/build_chronological_splits.py` implements the target-end purge and
20-calendar-day embargo used by the paper. It can rebuild the split when the
processed licensed window table is available; the repository does not claim
that excluded market data can be reconstructed from Git alone.

## Reproducibility and interpretation

The P-side DLPM is a conditional real-world path generator.  The Q-side is a
separate Student-t GARCH risk-neutral benchmark used for a controlled payoff
diagnostic, not an implied-volatility calibrated market-pricing claim.  The
economic scripts report both raw and diagnostic decompositions; they must not
be read as a standalone trading strategy.

The full methodology, time split, sampler protocol, results, and limitations
are in `paper/main.tex` (with a rendered copy at `paper/main.pdf`). All
reported result-table rows are generated by
`scripts/build_release_artifacts.py` from
`paper/data/authoritative_results_manifest.json` and its hashed source files.
The release preserves only reported results and their generating code rather
than an uncurated history of trial runs.

`BASELINES.md` maps every baseline reported in the manuscript to its exact
implementation and entry point.

`PAPER_REPRODUCTION.md` maps every paper table and figure to its generating
code and required local inputs.

`FINAL_RUN_MANIFEST.md` records the exact frozen hyperparameters, checkpoint
file hashes, fitted processor, and compact paper-data sources.  The binary
checkpoint itself is distributed separately as a release artifact rather than
committed to Git.
